# La Casa de Papel

Bienvenido al proyecto de sitio web estático dedicado a la serie de televisión española **La Casa de Papel**. Este proyecto presenta información sobre sus personajes principales, incluyendo descripciones, datos destacados y una página de contacto/registro.

## 📖 Descripción del proyecto

Este sitio fue desarrollado como una práctica de programación para internet, utilizando HTML, CSS y Bootstrap para crear una experiencia visual organizada y atractiva. El proyecto incluye:

- Una página principal con información general de la serie
- Páginas individuales para personajes como Álvaro Morte, Itziar Ituño, Pedro Alonso y Úrsula Corberó
- Una sección de personajes con tabla de información
- Un formulario de registro con diseño integrado

## ▶️ Instalación y uso

1. Descarga o clona este repositorio en tu computadora.
2. Abre el archivo `index.html` en tu navegador preferido.
3. Explora las páginas del sitio para ver la información de los personajes.

> No se requiere instalación adicional, ya que es un sitio web estático.
